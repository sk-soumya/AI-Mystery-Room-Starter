# AI Mystery Room — Runnable MERN Starter

A runnable React + Vite frontend and Express + MongoDB backend starter for the AI Mystery Room project.

## Requirements
- Node.js 20 or newer (Node 22 LTS recommended)
- npm
- Optional for persistence: MongoDB Atlas connection string
- Required for AI mysteries and generated images: Gemini API key
- Optional for generated spoken call recordings: ElevenLabs API key and voice ID

## Run on Windows
1. Extract the ZIP into your Downloads folder.
2. Open CMD in this folder.
3. Run `SETUP.bat` once.
4. Edit `server\.env` and add your API keys (see below).
5. Run `START.bat`.
6. Open http://localhost:5173.

The app has a clearly labelled local demo mode when `GEMINI_API_KEY` is empty. Demo mode uses sample fictional evidence and does not claim that sample images/audio were generated by AI. With a Gemini key, case text and images are generated by Gemini. With ElevenLabs configured, audio files are generated from fictional transcripts.

## Environment setup
Edit `server/.env`:

```env
PORT=5000
CLIENT_URL=http://localhost:5173
MONGODB_URI=
GEMINI_API_KEY=
GEMINI_TEXT_MODEL=gemini-2.5-flash
GEMINI_IMAGE_MODEL=gemini-3.1-flash-image
ELEVENLABS_API_KEY=
ELEVENLABS_VOICE_ID=
```

- Leave `MONGODB_URI` blank to use temporary in-memory development storage. Data disappears when the server restarts. Set it to a MongoDB Atlas connection string for persistent storage.
- Get a Gemini API key from Google AI Studio. Never place API keys in `client/` or commit `server/.env`.
- Set both ElevenLabs variables to enable audio generation. Without them, the app shows the transcript and an explicit audio-not-configured message.

## What is implemented
- Create case from premise and difficulty (Easy / Medium / Hard).
- Gemini structured mystery generation with deterministic demo fallback.
- Difficulty-specific suspect, evidence, category and hint counts.
- Gemini image evidence generation when configured.
- ElevenLabs audio generation when configured.
- Evidence discovery, hint limits, one final accusation and server-side scoring.
- Separate private solution collection/document; normal case APIs never return culprit or solution.
- Demo mode so the flow can be tested before API keys are added.

## Important limitations
This is an MVP starter. It does not include user accounts, payment, rate limiting at an edge/CDN, cloud object storage, or production observability. Generated files are stored locally in `server/uploads` for development. Before public deployment, add authentication/session ownership, per-user rate limits, durable object storage, request timeouts/queues for long generations, and moderation appropriate to your use case. All cases/evidence must remain fictional.
